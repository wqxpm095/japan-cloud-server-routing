## 选日本云服务器，先分清四种线路

线路类型决定回程质量，这是比 CPU 内存更值得先看的东西。日本机房常见的四种线路，适配的人群完全不同：

- **软银（SoftBank）**：对联通用户友好，六六云、Vultr 东京机房走的都是软银线路；
- **CN2 GIA**：电信优化的高端线路，代表是搬瓦工和 DMIT，但价格贵一截，搬瓦工日本 CN2 GIA 最低款要 $89.99/月；
- **IIJ**：日本本土骨干运营商，大阪机房常见，电信回程表现不错；
- **普通国际 BGP**：便宜，但晚高峰回程可能绕路。

## 大阪 Starter 实测：数据比宣传靠谱

第三方测评（2022 年底发布）对大阪 Starter 档做过完整测试，结论先说：**电信方向表现最好，联通中等，移动一般。**

具体数据。电信方向：上海电信延迟 59.98ms、下载 805.73 Mbps；南京电信下载 809.05 Mbps、丢包 0.5%；广州电信延迟 64.10ms、丢包 0.3%。联通方向：上海 5G 延迟 106.78ms，无锡测点下载只有 16.83 Mbps、丢包 1.0%，明显吃亏。移动方向：北京延迟 177.99ms、成都 100.61ms、银川 119.41ms，整体延迟高出一截。

回程路由是这套数据的关键：大阪发出的流量先经 IIJ（AS2497），再转电信 202.97 骨干回大陆，广州电信末跳 69.34ms；联通方向走 AS4837。也就是说，电信用户拿到的是「IIJ + 电信骨干」的回程组合，这解释了为什么电信数据明显好于联通移动。

两个需要注意的点。第一，测评确认大阪机器是日本原生 IP，对做日本本地业务的用户有价值。第二，测试机 CPU 是 Intel E5-2678 V3，Geekbench 单核 618 分——这是一颗老至强，磁盘 I/O 约 210 MB/s。建站、反代、轻量应用完全够，想跑编译或数据库密集型任务就别指望它了，那个需求该看 Performance 系列。

这份测评毕竟发布于 2022 年底，硬件批次可能已经更新。好在 V.PS 公开了各机房的 Looking Glass 和测速文件（东京测速地址 nrt.lg.v.ps），下单前用你自己的运营商跑一遍，比看任何人的数据都准。
